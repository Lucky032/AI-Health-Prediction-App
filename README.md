# AI Health Prediction Application

## Overview
A Flask-based application for managing patient records, storing health measurements in MySQL, and generating AI-assisted health remarks using the Google Gemini API.

## Features
- Create, view, update, and delete patient records
- Store patient data in MySQL
- Validate patient details and input fields
- Generate AI-assisted health remarks using Google Gemini
- Web interface built with HTML and CSS

## Technology Stack
- Python
- Flask
- MySQL
- HTML and CSS
- Google Gemini API
